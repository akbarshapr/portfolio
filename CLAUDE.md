## Commands

This project uses **pnpm** (pinned via `packageManager`); don't use npm/yarn, which would create a second lockfile.

- `pnpm dev` — dev server at http://localhost:3000
- `pnpm build` — production build (also runs type checking)
- `pnpm start` — serve the production build
- `pnpm lint` — ESLint 9 flat config (`eslint.config.mjs`, Next core-web-vitals + TypeScript rules); pass paths to lint specific files, e.g. `pnpm lint app/page.tsx`
- `pnpm exec tsc --noEmit` — type check without building

There is no test framework set up yet.

## Stack and architecture

A freshly scaffolded `create-next-app` project: Next.js 16 (App Router only, in `app/`), React 19, TypeScript (strict), Tailwind CSS v4.

- **Next.js 16 is newer than most training data.** Per `AGENTS.md`, check the bundled docs in `node_modules/next/dist/docs/` (`01-app/` covers the App Router) before using any Next API.
- **Route type helpers are global.** `app/layout.tsx` uses `LayoutProps<"/">` without an import; these types (`LayoutProps`, `PageProps`, etc.) are generated by Next into `.next/types` / `.next/dev/types` during `dev`/`build`. If they appear missing, run `pnpm dev` or `pnpm build` once.
- **Tailwind v4 is configured in CSS, not JS.** There is no `tailwind.config.*`; design tokens live in `app/globals.css`: color variables on `:root` mapped to utilities in `@theme inline` (`background`, `foreground`, `muted`, `subtle`, `line`, `surface`, `accent`), fonts from `next/font` in `layout.tsx` (`font-sans` DM Sans, `font-mono` JetBrains Mono), a fluid type scale (`text-label`, `text-body`, `text-lead`, `text-heading`, `text-display`), `text-giant` (footer name), `rounded-card` and `py-section`. There is no OS dark mode; the `theme-dark` class flips a subtree to the dark palette (`<Section tone="dark">` applies it). PostCSS uses `@tailwindcss/postcss`.
- **UI primitives** live in `components/ui/` (`Container`, `Section`, `Heading`, `Label`, `ButtonLink`, `Card`, `Pill`, `Divider`, `ArrowIcon`, `Nav`, `Stat`, `ListRow`, `ProjectCard`); compose them instead of repeating raw classes. Merge class names with `cn()` from `lib/cn.ts`. `/styleguide` (noindex, unlinked) renders every token and component in light and dark. Section components that map portfolio data to UI are in `components/Sections.tsx`.
- **Import alias:** `@/*` resolves to the repo root (e.g. `@/app/...`), not to a `src/` directory.
- `pnpm-workspace.yaml` disables install scripts for `sharp` and `unrs-resolver` (`allowBuilds: false`).
